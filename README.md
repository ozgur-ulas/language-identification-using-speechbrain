# Language Identification using SpeechBrain

This project evaluates the SpeechBrain VoxLingua107 ECAPA-TDNN model on Turkish and English speech recordings.

## Technologies

- Python
- SpeechBrain
- PyTorch
- Scikit-Learn
- Pandas
- Matplotlib

## Dataset

- 10 Turkish voice recordings
- 10 English voice recordings

## Evaluation

- Classification Accuracy
- Classification Report
- Confusion Matrix

## Conclusion

- Overall Accuracy: 50%
- Turkish Accuracy: 100%
- English Accuracy: 0%
- Total Samples: 20
- Model: SpeechBrain VoxLingua107 ECAPA-TDNN

### Discussion

The model achieved excellent performance for Turkish recordings while struggling with English recordings recorded by the same speaker. This suggests that accent, pronunciation style, recording quality, or dataset bias may influence language identification performance.
