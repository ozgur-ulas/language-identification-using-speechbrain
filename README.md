# Language Identification using SpeechBrain

This project evaluates the SpeechBrain VoxLingua107 ECAPA-TDNN model on Turkish and English speech recordings.

## Technologies

- Python
- SpeechBrain
- PyTorch
- Scikit-Learn
- Pandas
- Matplotlib

## Dataset

- 10 Turkish voice recordings
- 10 English voice recordings

## Evaluation

- Classification Accuracy
- Classification Report
- Confusion Matrix

## Conclusion

Overall Accuracy: 50%
Turkish Accuracy: 100%
English Accuracy: 0%
Total Samples: 20
Model: SpeechBrain VoxLingua107 ECAPA-TDNN
